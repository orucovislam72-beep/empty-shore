# Иконка приложения — исходники

`icon_1024.png` и уменьшенные копии (512, 192, 144, 96, 72, 48) — исходная иконка «Пустого Берега»:
топор в скале на фоне тёмной волны.

Сгенерировано: Viktor AI image generation (модель gpt-image-2.5-sunburst, OpenAI GPT Image) по заказу проекта;
уменьшение — Pillow (LANCZOS). Запись — в `CREDITS.md`.

Папка не импортируется Godot (`.gdignore`) и не попадает в сборку. В игре используются производные файлы
из `assets/icons/`:

| Файл | Что это |
|------|---------|
| `app_icon_512.png` | иконка проекта (`application/config/icon`) |
| `app_icon_192.png` | иконка Android `launcher_icons/main_192x192` |
| `adaptive_foreground_432.png` | передний слой адаптивной иконки Android 432×432 (вся картинка; маска лаунчера обрезает края, топор остаётся в центральной безопасной зоне 66 %) |
| `adaptive_background_432.png` | задний слой адаптивной иконки — сплошной цвет `#1a1c1e` |
