## Управление и интерфейс
- Редактор раскладки HUD: перетаскивание каждой кнопки пальцем, размер и прозрачность по отдельности, сохранение раскладки (сейчас — общий размер/прозрачность и режим для левшей).
- Обзор гироскопом (по желанию игрока), с отдельной чувствительностью.
- Собственные иконки кнопок в едином стиле вместо подписей; свои переключатели в настройках (стандартные мелковаты).
- В Godot 4.7 появился встроенный узел `VirtualJoystick`. Сравнить с нашим `TouchStick` (мультитач-маршрутизатор, автобег по двойному толчку) — возможно, заменить.
- Раздельная чувствительность обзора по осям X/Y; кривая отклика стика.
- Экран «Лицензии» в меню (нужен для этапа 6).

## Графика и производительность
- Опция рендера Mobile (Vulkan) для сильных устройств — только после проверки на телефонах.
- Ночное освещение и смена дня и ночи (этап 1) — продумать дешёвый вариант без динамических теней ночью.
- Ветер для травы через вершинный шейдер (дёшево), если позволит бюджет.
- Физическая интерполяция (`physics/common/physics_interpolation`) для плавности при 60 к/с.

## Инфраструктура

- Сохранять снимки экрана сцен в артефактах CI (нужен рендер, например Xvfb + Mesa).
