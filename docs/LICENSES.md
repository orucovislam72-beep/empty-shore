# Заметки о лицензиях

- **Код и ассеты проекта.** Принадлежат заказчику. Лицензия для исходников проекта пока не выбрана —
  это решение заказчика (закрытый проект или открытая лицензия). До решения файл `LICENSE` не добавляем.
- **Godot Engine (MIT).** При распространении игры нужно указать текст лицензии Godot и сторонних библиотек движка
  (например, в разделе «Об игре» / «Лицензии»). Текст: https://godotengine.org/license и `COPYRIGHT.txt` движка.
  Сделаем экран «Лицензии» на этапе 6 (выпуск).
- **Open Sans (OFL 1.1)** — встроен в движок, условия выполняются вместе с уведомлением Godot.
- **GUT (MIT)** — только для тестов, в сборку не попадает (`exclude_filter` в `export_presets.cfg`).
- **Новые ассеты.** Только оригинальные или под MIT, Apache 2.0, BSD, CC0, OFL. Перед добавлением — строка в `CREDITS.md`
  (название, автор, ссылка, лицензия). Без лицензии — не добавляем.
- **Оригинальность.** Не используем код, модели, текстуры, звуки, интерфейс, названия предметов, логотипы и название
  других игр жанра (в т. ч. Rust).
- **Иконка приложения (этап 1).** Сгенерирована по заказу проекта сервисом генерации изображений Viktor
  (модель gpt-image-2.5-sunburst, OpenAI GPT Image) и уменьшена Pillow. Это не сторонний ассет под открытой лицензией,
  а собственная картинка проекта; права на результат генерации определяются условиями сервиса/OpenAI
  (по условиям OpenAI права на выход принадлежат пользователю). Перед выпуском (этап 6) стоит ещё раз сверить условия
  и при желании перерисовать иконку вручную. Исходники — `assets/icons/source/`.
